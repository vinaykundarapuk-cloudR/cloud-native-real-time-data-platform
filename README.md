# Cloud-Native Real-Time Data Engineering & Analytics Platform

An end-to-end cloud-native data platform designed to ingest, process, validate, analyze, and visualize real-time business data.

## Overview

This project simulates a production-style e-commerce data platform.

It collects customer, product, order, payment, and activity events, processes them through a scalable data pipeline, stores analytical datasets, and delivers business intelligence and machine learning insights.
